Demonstration modes

The public GitHub Pages version runs in the browser. It shares the interface and booking rules with the Express/EJS application but does not run Express or MySQL. The local Express version independently validates inputs, calculates prices and keeps temporary synthetic details in an expiring session. Optional MySQL mode reads an isolated synthetic catalog. Neither mode allocates real inventory or processes payments.

Use sample names and @example.com addresses. The static demo keeps synthetic progress in sessionStorage. Start again clears it.
